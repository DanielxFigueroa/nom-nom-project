# Issue #74: PCOS Assistant: Native On-Device AI Pipeline & Clinical Prompts

Link to issue: https://github.com/DanielxFigueroa/nom-nom-project/issues/74

## Summary
Implement the core on-device intelligence service (`PCOSService`) that analyzes recipe ingredients and instructions against the user's active PCOS focus areas (`PCOSSettings`) and generates structured, nuanced suggestions (smart swaps, pairing tips, glycemic notes).

The service runs 100% locally and offline on-device without network dependencies, utilizes Apple Foundation Models / CoreML text generation runtime when available, and provides a robust clinical heuristic fallback parser when model compilation is pending or on older iOS versions. It also caches analysis results by `recipe.id + recipe.updatedAt` (incorporating ingredients and settings hash) to prevent redundant compute.

## Technical Design & Tasks

### Task 1: Structured Output Model — `NomNom/Models/PCOSAnalysisResult.swift`
- Create `PCOSAnalysisResult` conforming to `Codable`, `Equatable`, `Hashable`, `Sendable`.
- Create nested `SwapSuggestion`:
  - `var id: String { originalIngredient }`
  - `originalIngredient: String`
  - `suggestedSwap: String`
  - `rationale: String`
  - `adjustedQuantity: String?`
  - `adjustedUnit: String?`
- Root fields:
  - `summaryNote: String`
  - `glycemicImpactBadge: String` (e.g. "Blood Sugar Balanced", "Moderate Glycemic", "High Glycemic Impact")
  - `swaps: [SwapSuggestion]`
  - `pairingTips: [String]`
  - `positiveHighlights: [String]`
- Support robust decoding from both camelCase and snake_case JSON outputs generated by LLMs.
- Provide helper properties for UI styling (e.g. badge colors/icons) and preview fixtures.

### Task 2: Clinical Prompt Engineering — `NomNom/Core/PCOSPromptBuilder.swift`
- Construct clinical prompts adopting contemporary PCOS nutritional guidelines:
  - Core philosophy: "Add before you subtract" (respectful, non-restrictive tone).
  - Emphasize macronutrient pairing (pairing carbs with fiber, protein, and healthy fats).
  - Conditioned on active `focusAreas`:
    - `insulinResistance`: Low glycemic impact, food sequencing (veggies/protein first), complex carbohydrates.
    - `inflammation`: Omega-3s, antioxidant herbs/spices (turmeric, ginger), polyphenols, minimizing inflammatory seed oils.
    - `highProtein`: Target 25-35g protein per meal for hormonal satiety, gentle protein boosters.
    - `dairySensitivity`: Dairy alternatives, lactose sensitivity guidance.
    - `glutenSensitivity`: Gluten-free whole grains (quinoa, buckwheat, certified GF oats), gut lining support.
  - Conditioned on `suggestionStyle`:
    - `.gentleAdditions`: Prioritize pairing tips and positive additions without removing base ingredients.
    - `.directSwaps`: Suggest direct 1-to-1 replacements with proportional quantities.
  - Formatted for strict JSON output schema.

### Task 3: Structured Heuristic Engine & Offline Fallback — `NomNom/Core/PCOSHeuristicAnalyzer.swift`
- Provide a rich, deterministic, clinical on-device heuristic analyzer:
  - Detect glycemic impact based on carbohydrates, refined sugars, fibers, and protein density.
  - Identify ingredients corresponding to active PCOS focus areas (e.g., dairy, gluten, high glycemic index, inflammatory oils).
  - Generate thoughtful `SwapSuggestion` items tailored to `.gentleAdditions` or `.directSwaps`.
  - Provide actionable `pairingTips` (e.g. food sequencing, apple cider vinegar, post-meal walks, healthy fat pairings).
  - Extract `positiveHighlights` from recipe ingredients (e.g. healthy fats, fiber, seeds, leafy greens, antioxidant herbs).
  - Fully offline, deterministic, zero network calls.

### Task 4: Core Service & Cache — `NomNom/Core/PCOSService.swift`
- Create `PCOSService`:
  - `shared` singleton instance.
  - Methods:
    - `analyze(recipe: Recipe, ingredients: [Ingredient], settings: PCOSSettings) async throws -> PCOSAnalysisResult`
    - `analyze(recipe: Recipe, settings: PCOSSettings) async throws -> PCOSAnalysisResult`
  - Integration with on-device Apple Foundation Models / CoreML runtime, with graceful fallback to `PCOSHeuristicAnalyzer`.
  - Analysis Cache:
    - Caches results keyed by `recipe.id + recipe.updatedAt` (with fallback to `createdAt` and ingredient/settings hash).
    - In-memory thread-safe storage + local persistent cache in `UserDefaults`.
    - Cache invalidation when recipe or user settings change.
  - Update `Recipe.swift` to add optional `updatedAt: String?` property (CodingKey `updated_at`).
