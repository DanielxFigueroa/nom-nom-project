# Issue #75: PCOS Assistant: Recipe Detail Review & Insights Card UI

Link to issue: https://github.com/DanielxFigueroa/nom-nom-project/issues/75

## Summary
Display a dedicated, non-intrusive, collapsible "PCOS Nutrition Insights" card (`PCOSInsightsCard`) on `RecipeDetailView` when the PCOS Assistant feature is enabled in settings.

The card surfaces on-device AI nutritional guidance generated by `PCOSService` (Issue #74), organized into:
1. Glycemic & metabolic impact badge and summary.
2. Positive Highlights (reinforcing what's already great about the recipe).
3. Smart Swaps (original vs. suggested ingredient cards with clinical rationale).
4. Order of Eating & Pairing Advice (macronutrient sequencing and glucose-buffering tips).

When disabled in settings, the card is completely absent with zero UI clutter.

---

## Technical Tasks

### Task 1: Generic Loading State Model — `NomNom/Models/LoadingState.swift`
- Create `LoadingState<Value>` generic enum:
  - `.idle`
  - `.loading`
  - `.loaded(Value)`
  - `.failed(String)`
- Add convenience getters: `value: Value?`, `isLoading: Bool`.
- Conformance to `Equatable`, `Sendable`.

### Task 2: View Model Integration — `NomNom/Recipes/RecipeDetailModel.swift`
- Add `pcosSettingsStore: PCOSSettingsStore` property (defaulting to `.shared`).
- Add `isPCOSEnabled: Bool` computing `pcosSettingsStore.settings.isEnabled`.
- Add `pcosAnalysisState: LoadingState<PCOSAnalysisResult> = .idle`.
- Add `isPCOSInsightsExpanded: Bool = true`.
- Implement `loadPCOSAnalysis(forceRefresh: Bool = false)`:
  - Checks `isPCOSEnabled`. If disabled, keep/set `.idle` and return early.
  - Sets `pcosAnalysisState = .loading`.
  - Calls `PCOSService.shared.analyze(recipe: recipe, ingredients: ingredients, settings: pcosSettingsStore.settings)`.
  - On success sets `.loaded(result)`.
  - On error sets `.failed(error.localizedDescription)`.
- Trigger `loadPCOSAnalysis()` inside `load()` when `isPCOSEnabled`.

### Task 3: Collapsible Insights Card UI — `NomNom/Components/PCOSInsightsCard.swift`
- Build `PCOSInsightsCard(model: RecipeDetailModel)`:
  - Header:
    - Sparkles icon (`sparkles`) in `Color.nnTint`.
    - Title "PCOS Nutrition Insights".
    - Glycemic impact badge (e.g. "Blood Sugar Balanced" or "Moderate Glycemic").
    - Chevron collapse/expand indicator with accessible button toggle.
  - Loading State:
    - Clean shimmer / loading skeleton view with animated opacity/gradient.
  - Error State:
    - Friendly error callout with "Retry" action button.
  - Collapsible Content:
    - Summary Note text.
    - Positive Highlights section with checkmark/sparkle icons.
    - Smart Swaps section:
      - Original ingredient card (subtle strike/badge).
      - Suggested swap card with adjusted quantity and unit.
      - Rationale explaining the hormonal/metabolic reason.
    - Order of Eating & Pairing Advice section:
      - Actionable tips (e.g. veggies/protein first, fiber buffering, healthy fats).
  - Clean styling:
    - Background: `Color.nnTint.opacity(0.12)`.
    - Rounded corners (14pt) + subtle border.
    - Smooth animation on expand/collapse without disrupting recipe scroll view.

### Task 4: Detail View Embedding — `NomNom/Recipes/RecipeDetailView.swift`
- Insert `PCOSInsightsCard(model: model)` directly above ingredients section.
- Only rendered when `model.isPCOSEnabled`.
- Handle `.onChange(of: model.pcosSettingsStore.settings.isEnabled)` to auto-load insights when turned on.
